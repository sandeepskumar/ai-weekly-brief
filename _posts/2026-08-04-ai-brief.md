## 3. Agentic Framework Updates

- **Claude Agent SDK** (renamed from Claude Code SDK): June brought hierarchical subagent spawning and fallback model chains. Example: a lead agent decomposes a migration task, spawns scoped subagents per module, and falls back from Opus to Sonnet on rate limits. Subscription usage now draws from a separate monthly Agent SDK credit (since June 15). ([Morph](https://www.morphllm.com/ai-agent-framework))
- **LangGraph** overtook CrewAI in GitHub stars; Q2 added per-node timeouts, DeltaChannel, and v2 streaming. Its graph model maps cleanly to enterprise needs — think of each node as a checkpointed workflow station with audit trails and rollback. ([NomadX](https://nomadx.ae/ai-agent-framework-comparison-2026/))
- **CrewAI** passed 52k GitHub stars; still the fastest path for role-based multi-agent teams (e.g., researcher → writer → reviewer crews). ([QubitTool](https://qubittool.com/blog/ai-agent-framework-comparison-2026))
- Rule of thumb: LangGraph for controlled production graphs, CrewAI for quick role-play teams, Claude Agent SDK when you want the harness (tools, subagents, permissions) built in.

## 5. When AI Goes Wrong

- **ChatGPT medical-advice lawsuit (July, San Francisco):** a man consulting GPT-4o about dizziness and unstable blood pressure was allegedly told to stay "recliner-bound" and wait for 8–10 more episodes; he later suffered a pulmonary embolism a doctor linked to that immobility. ([Forbes](https://www.forbes.com/sites/jessepines/2026/07/26/a-lawsuit-says-chatgpt-nearly-someone-heres-the-data-on-ai-diagnosis/))
- **Florida AG lawsuit vs OpenAI/Altman:** alleges inadequate risk warnings and growth prioritized over safety; part of a wider wave of wrongful-death and self-harm suits. ([Lawsuit Informer](https://lawsuitinformer.com/openai-lawsuits))
- **How to avoid:** hard-block medical/legal "reassurance" answers behind escalation prompts ("see a doctor now" defaults for symptom queries); red-team for sycophancy — models that minimize symptoms to keep users comfortable; add usage-pattern monitoring for vulnerable-user signals; and treat AI outputs as products (with recall/liability discipline), which is exactly the question courts are now deciding.

## 6. Evals: Latest Tools & How-To

- **Landscape:** Promptfoo, DeepEval, and Ragas are evaluation-first; Braintrust, LangSmith, and Phoenix lead with observability and do both. ([Inference.net](https://inference.net/content/llm-evaluation-tools-comparison/))
- **Promptfoo is now part of OpenAI** (announced March 9, 2026) with a commitment to stay open source and model-agnostic; its 500+ vector red-team suite is the most comprehensive in open source. ([aiml.qa](https://aiml.qa/llm-evaluation-framework-benchmark-2026/))
- **Braintrust how-to:** define a dataset of inputs (+ expected outputs), a task function calling your LLM, and scorers; Braintrust runs experiments and shows scores, diffs, and regressions. ([Braintrust guide](https://qaskills.sh/blog/braintrust-llm-evaluation-guide-2026))
- **Picking:** LangSmith if your stack is LangChain/LangGraph (native graph tracing); Promptfoo for CI-style prompt testing and security scans; Braintrust for experiment-driven regression tracking.
- **Practical loop:** version prompts → build a golden dataset from production failures → score with a mix of assertions and LLM-as-judge → gate deploys on eval regressions, same as unit tests.
