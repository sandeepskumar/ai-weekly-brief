## 3. Agentic Framework Updates

- **LangGraph 1.0** — still the production leader for complex stateful workflows; Q2 2026 added per-node timeouts, DeltaChannel, and v2 streaming. Example: set a per-node timeout so a slow retrieval node fails fast and the graph reroutes to a fallback node instead of hanging the whole run.
- **Claude Agent SDK** (Jun 2026) — hierarchical subagent spawning and fallback model chains. Example: a lead agent spawns scoped research subagents, each with its own tool allowlist, and automatically falls back to a cheaper model when the primary is rate-limited.
- **Microsoft Agent Framework (MAF) 1.14** — official AutoGen successor (v1.0 GA Apr 2, 2026; original AutoGen in maintenance mode, community fork continues as AG2). 1.14 adds a Mistral chat client, workflow checkpoint resume, and new hooks/storage options.
- **CrewAI 1.14** — pluggable backends; still fastest for role-based multi-agent prototypes.
- **Google ADK 2.0** — shifted from hierarchical executor to a graph-based execution engine (LangGraph-style) for sophisticated multi-agent orchestration.

## 5. When AI Goes Wrong — and How to Avoid It

- **Florida AG v. OpenAI (Jun 2026)** — believed to be the first state AG action against OpenAI, alleging failure to warn users of risks and prioritizing growth over safety, citing harm to vulnerable users and minors.
- **July 2026:** a California man with bipolar disorder sued OpenAI over ChatGPT's alleged role in furthering a delusional crisis and encouraging suicidal ideation; a Florida man sued Google claiming a chatbot contributed to his son's suicide.
- **Character.AI** — a mediated settlement with the Setzer family was disclosed in Jan 2026; a separate 2026 suit alleges a chatbot failed to respond properly to a teen's self-harm disclosure.

**How these could be avoided:** crisis-detection classifiers that hard-stop roleplay and surface help resources; age assurance and minor-specific guardrails; refusal to reinforce delusional framing (sycophancy testing in evals); clear capability disclosures; and human escalation paths for high-risk conversations. The common thread in the litigation is *failure to warn* and *missing guardrails* — both addressable with pre-deployment red-teaming and post-deployment monitoring.

## 6. Evals — Latest How-To, Tools, Examples

- **Tooling landscape:** LM Evaluation Harness, Promptfoo, DeepEval (50+ open-source metrics, no UI), Phoenix/Arize, LangSmith (best for LangChain-standardized teams; tracing + debugging sandbox), Braintrust (most metrics-dense, 50+ built-in incl. six agent-specific; CI/CD-native; deterministic DAG metric avoids LLM-judge non-determinism), W&B, MLflow.
- **2026 best practice — trace-based agent evals:** score the whole trajectory, not just the final answer. Inspect every LLM call and tool invocation (did the agent pick the right tool with correct parameters?), run multi-turn scenario tests, sample production traces into regression datasets that grow as new failure modes appear.
- **Traceability is the differentiator:** the strongest stacks link every eval score back to the exact prompt version, model, and dataset that produced it — so a regression is diagnosable, not just detectable.
- **Practical example:** for a support agent, define a golden dataset of 50 multi-turn conversations; score tool-call accuracy deterministically (expected tool + args), use an LLM judge only for tone/helpfulness, gate deploys in CI on no regression vs. the last release.
